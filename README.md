# noctalia-user-templates

Self-written Noctalia theming templates (theme templates for programs) + local-only templates.

- user-templates/ + user-templates.toml — ~/.config/noctalia user templates (fish, mpv, uosc, vim, yt-x, doris, dunstrc, oxwm)
- noctalia-colors-extended.lua — ~/.config/noctalia/templates
- matugen-template.lua — ~/.config/nvim/lua (nvim-base16 template input)
- tahoe-icons — local-only template (not in community catalog)
